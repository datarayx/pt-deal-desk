# SCREENS.md — Screen inventory

Legend: **C** = CEO, **A** = Accountant.

## Auth
| Screen | Who | Contents |
|---|---|---|
| Login | All | Logo, email, password, "forgot password". Split layout: form left, calm brand panel right |
| Reset password | All | Standard flow |

## CEO area
| Screen | Route | Contents |
|---|---|---|
| Dashboard | `/dashboard` | KPIs (active deals, pipeline value, outstanding balance, overdue amount, portfolio at risk, fees earned MTD/YTD, fees receivable); Ongoing transactions table (client, financier, amount, stage, deficiency, days in stage); Repayments due next 14 days; Overdue list with "Log call" action; Pipeline by stage chart; Pipeline conversion chart; Fees earned vs received chart; Top referrers |
| Clients | `/clients` | Table: name, type, sector, KYC status, latest credit rating, active deals, outstanding, referrer. Filters: type, sector, KYC status |
| New client | `/clients/new` | Step 1 type → Step 2 details → Step 3 directors (company) → Step 4 documents → Step 5 review |
| Client 360 | `/clients/[id]` | Header (name, type, KYC badge, reliability badge); tabs: Overview · KYC & Documents · Directors · Credit checks · Deals · Repayments · Activity |
| Deals (Kanban/Table) | `/deals` | Toggle view; filters: financier, stage, facility type, referrer, date |
| New deal | sheet | Client, financier, facility, amounts, rate/month, tenor, purpose, collateral/guarantor, fees, referrer & referral fee |
| Deal detail | `/deals/[id]` | Header (amount, stage, financier, next due); tabs: Overview · Requirements (checklist + deficiencies) · Repayments · Fees · Documents · Activity. Actions: Move stage, Decline, Disburse |
| Repayments | `/repayments` | All instalments; tabs: Due soon · Overdue · Reported (awaiting confirmation) · Confirmed. Actions: Record reported payment (with proof), Confirm, Log call |
| Follow-ups | `/follow-ups` | Call tasks: client, deal, due, assigned, outcome, promise-to-pay date |
| Referrers | `/referrers`, `/referrers/[id]` | Directory + stats + fees payable/paid |
| Financiers | `/financiers`, `/financiers/[id]` | Directory, rate range, facility types, requirement checklist template, deals with them |
| Outbox | `/outbox` | Emails generated by reminders (demo: not actually sent) |
| Settings | `/settings/*` | Users & roles · Notification recipients · Reminder timings · Deal stages · Facility types · KYC document checklists · Fee defaults · Company profile & branding |

## Accountant area (CEO also sees)
| Screen | Route | Contents |
|---|---|---|
| Finance dashboard | `/finance` | Cash/bank balance, receivables, payables, this month's income & expenses, P&L snapshot |
| Fee receivables | `/finance/receivables` | Fee lines: source (commission/client fee/collateral fee), deal ref (no client details for Accountant beyond name/ref), amount, earned date, status. Record receipt |
| Payables | `/finance/payables` | Referral fees and bills payable. Record payment |
| Journals | `/finance/journals` | List + new manual journal (balanced lines enforced) |
| Expenses & receipts | `/finance/transactions` | Quick entry forms that post journals |
| Chart of accounts | `/finance/accounts` | Tree, add/edit, lock system accounts |
| General ledger | `/finance/ledger` | Per account with running balance |
| Reports | `/finance/reports` | Trial balance · Profit or loss · Financial position · Cash flows. Period picker (month/quarter/year/custom), compare prior period, export Excel/PDF |
| Period close | `/finance/periods` | Lock/unlock months |

Sidebar, top bar with ⌘K search and notification bell (dropdown of alerts, "mark all read"), user menu (profile, theme toggle, sign out).
